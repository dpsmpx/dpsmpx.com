Маршрут

  1. 2023

    Начало

    Аккаунт GitHub и первые открытые проекты: игры, редактор и утилиты на C++, Python и PascalABC.NET.

    Ранние открытые проекты: Andors-Love — пошаговая RPG на C++ (2023), TrueJointTileMaker — редактор пиксельной графики и карт для неё (2024), PixRogue — Rogue в пиксельном стиле на Python (2026).

  2. 11.09.2026

    Игра

    Первый коммит Galdhold (прежде VoxelRPG) — 234 файла и 30 801 строка, написанные до репозитория.

    Игру начал ради интереса — проект вырос дальше планов.

  3. 25–29.09.2026

    Метод

    В репозитории игры появляются правила для сессий ИИ (CLAUDE.md), на следующий день — список незавершённого (TODO.md).

Конечная цель

«Сначала построить качественные самостоятельные системы. Затем заставить их корректно понимать друг друга. И только после этого построить единое приложение…»

— dpsmpx, план экосистемы, 06.10.2026
Схема цели списком: приложение, ядра, направления и основание

DPmetaApp

Одно мобильное приложение над законченными системами: общая модель состояния, событий и знаний. (есть сейчас)

Два ядра

  • Общее ядро — Состояние, события, происхождение данных. (план)
  • Локальное ядро ИИ — Поиск, рассуждение, маршрутизация. (план)

Разработка

  • Galdhold — воксельная action-RPG с открытым процедурным миром (закрыты этапы: движок, живое поселение, регионы; идёт подготовка версии 1)
  • DPlang — разрабатываю собственный язык программирования — DPlang (язык на ранней стадии: компилятор в разработке, собирает программы для Linux, Windows и Android)
  • среда разработки DPlang (план)
  • DP-Verify — общий каркас проверок для репозиториев автора (кандидат версии 1.0; его проверки подключены в Galdhold)
  • DPmeta — карта экосистемы, контракты между репозиториями и риски (три прохода по экосистеме — 5 октября 2026)
  • GitHub
  • ещё 1 проект без публичного имени

Знание

  • заметки и инструменты к ним
  • DPprofile — проверяемая история пути разработки — источники, факты, хронология (выполнено 4 этапа из 6; текст книги не пишется)
