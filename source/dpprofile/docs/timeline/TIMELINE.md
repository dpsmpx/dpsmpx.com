# Хронология

Упорядоченные события со ссылками на факты — без пересказа и
толкований. Строка: дата, событие одной фразой до 160 знаков, номера
фактов. Дата строки равна дате (`date`) каждого факта строки; строки
идут по возрастанию даты. Проверяет `tools/verify/check_timeline.py`.

Хронология выборочная: не каждый факт — событие. Чего источники не
покрывают — `docs/timeline/GAPS.md`.
