# Выводы и гипотезы

Выводы из фактов `docs/facts/`. Каждый вывод ссылается на один или
несколько активных фактов; без этой опоры он не записывается.
Схему и ссылки проверяет `tools/verify/check_insights.py`, оценочные
слова — `tools/verify/check_forbidden.py` (D-07).

Выводы копятся на этапе 3 (`docs/direction/ROADMAP/stage-3.md`); до
него каталог может быть пуст.

## Уровни

| Файл | `kind` | `level` | Что это |
|---|---|---|---|
| `I-NNNN.md` | `insight` | `observed` | наблюдаемый вывод: прямо следует из перечисленных фактов, без обобщения за их пределы |
| `I-NNNN.md` | `insight` | `bounded` | ограниченный вывод: верен в названных пределах; поле `limits` говорит, чего он не утверждает |
| `H-NNNN.md` | `hypothesis` | — | гипотеза: спорный вывод; поле `test` говорит, какой будущий факт её подтвердит или опровергнет |

Гипотезы лежат в том же каталоге, но с другим префиксом номера, чтобы
их нельзя было спутать с выводами.

## Схема

Front matter — по D-04; после него можно раздел `## Обоснование`:
цепочка от фактов к выводу. Номера фактов в обосновании — только из
поля `facts`.

| Поле | Обязательно | Значение |
|---|---|---|
| `id` | да | `I-NNNN` или `H-NNNN`, совпадает с именем файла |
| `kind` | да | `insight` для `I-`, `hypothesis` для `H-` |
| `level` | у `insight` | `observed` или `bounded`; у гипотезы поля нет |
| `statement` | да | одно предложение до 400 знаков, с точкой в конце |
| `facts` | да | список `F-NNNN`, не пустой; все факты существуют и активны |
| `limits` | у `bounded` | чего вывод не утверждает |
| `test` | у `hypothesis` | что подтвердит или опровергнет гипотезу |
| `recorded` | да | ISO; не раньше `observed` каждого факта из `facts` |
| `status` | нет | `active` (по умолчанию) или `revised` |
| `revised_by` | при `revised` | `I-NNNN` или `H-NNNN`, который заменяет этот |

Новые факты, которые противоречат выводу, — повод пересмотреть его:
старый получает `status: revised`, новый объясняет, что изменилось.

Шаблон:

```
---
id: I-NNNN
kind: insight
level: bounded
statement: Одно предложение, которое следует из фактов.
facts: [F-NNNN, F-NNNN]
limits: Чего вывод не утверждает.
recorded: YYYY-MM-DD
---

## Обоснование

Как из F-NNNN и F-NNNN следует вывод.
```
