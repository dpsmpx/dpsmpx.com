# Факты

Только атомарные факты: одно проверяемое утверждение — один файл
`F-NNNN.md`. Интерпретаций, оценок и выводов здесь нет — они в
`docs/insights/`. Схему проверяет `tools/verify/check_facts.py`,
неизменяемость — `tools/verify/check_history.py` (D-06).

## Схема

Файл состоит только из front matter (D-04): строки `ключ: значение` и
списки `[a, b]` в одну строку. Текста после front matter нет.

| Поле | Обязательно | Значение |
|---|---|---|
| `id` | да | `F-NNNN`, совпадает с именем файла |
| `kind` | да | `fact` |
| `date` | да | ISO; дата события или состояния, которое описывает факт (`docs/sources/CITATION.md`, «Даты») |
| `statement` | да | одно предложение до 300 знаков, с точкой в конце; без оценок и выводов |
| `area` | да | `project`, `process` или `result` (ниже) |
| `projects` | да | теги из `docs/direction/SCOPE.md`, «Теги проектов» |
| `basis` | да | `observed` или `stated` (ниже) |
| `source` | да | `S-NN` из `docs/sources/REGISTRY.md` |
| `source_type` | да | `commit`, `file`, `release`, `url` или `note` |
| `ref` | да | место в источнике; форма зависит от `source_type` (`docs/sources/CITATION.md`, «Ссылки») |
| `observed` | да | ISO; когда источник проверен при записи; не раньше `date` |
| `refines` | нет | `F-NNNN` — факт, который этот уточняет |
| `marks` | нет | метки из словаря: `steam-release` — выпуск VoxelRPG в Steam (D-02) |
| `status` | нет | `active` (по умолчанию) или `superseded` |
| `superseded_by` | при `superseded` | `F-NNNN` — факт, который заменяет этот |
| `revised_by` | при `superseded` | `D-NN` — решение о замене (D-06) |

**Область (`area`):**

- `project` — существование проекта, имена, состав, сроки, решения о
  продукте и архитектуре;
- `process` — как ведётся работа: решения о процессе, артефакты
  процесса, история коммитов и PR, проверки;
- `result` — внешние результаты и их отсутствие: релизы, публикации,
  страницы магазина, состояние выпуска.

**Основание (`basis`):**

- `observed` — факт и есть наблюдаемое содержимое источника: коммит
  существует и вот его заголовок, файл есть на коммите, поиск на
  странице вернул ноль результатов;
- `stated` — источник сообщает о чём-то вне себя: запись автора о
  решении, описание проекта в README. Формулировка тогда называет, где
  это записано: «В `DECISIONS.md` Galdhold (Р14) записано: …».

## Как добавить факт

1. Источник уже есть в `docs/sources/REGISTRY.md`; нет — сначала строка
   там (и в `docs/sources/MAP.md`, если это файл репозитория).
2. Следующий свободный номер — наибольший `F-NNNN` плюс один; номера не
   переиспользуются.
3. Файл по шаблону ниже; формулировка — что видно в источнике, и только.
4. Событие для хронологии — строка в `docs/timeline/TIMELINE.md`.
5. `tools/verify/run.sh --quick`.

Шаблон:

```
---
id: F-NNNN
kind: fact
date: YYYY-MM-DD
statement: Одно предложение о том, что видно в источнике.
area: project
projects: [voxelrpg]
basis: observed
source: S-NN
source_type: commit
ref: <40 шестнадцатеричных знаков>
observed: YYYY-MM-DD
---
```

Исправить закоммиченный факт нельзя — только заменить (D-06).
