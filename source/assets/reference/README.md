# REFERENCE_IMAGE — настоящие фотографии автора

Здесь — только фотографии автора, которые он сам прислал как образ
(Д10, Д18). Каждая — с записью в `data/provenance/assets.yaml` (вид
`REFERENCE_IMAGE`) и строкой в `docs/PROVENANCE.md`, §3.

- Имя файла: `author/<ГГГГ-ММ-ДД>-author-reference-<NN>.jpg`.
- Перед добавлением — удалить метаданные (EXIF/XMP, геометки,
  комментарии); проверка `provenance` это контролирует.
- Разрешено в работах: кадрирование, тон, монохром/дуотон, виньетка,
  маска краёв. Запрещено: изменение черт и формы, генеративное
  «улучшение», генерация «по мотивам», передача в сервисы генерации.
- Интерьер на фото — личное: в работах затемняется до нечитаемости.
- Права фотографа на публичное использование подтверждает автор
  (`docs/legal/RIGHTS_MATRIX.md`).
