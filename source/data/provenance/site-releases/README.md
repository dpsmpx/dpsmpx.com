# Реестр выпусков сайта (Д41, П2-20)

Продолжение реестра происхождения (`docs/PROVENANCE.md`) для того, что
ушло на рабочий сайт. Каждая выгрузка (`site deploy`, `publish …
--production`) — каталог `<id>/`, где id — время выгрузки UTC
(`2026-10-17T120000Z`):

- `<id>/manifest.json` — схема `site-release/v1`: коммит, адрес сайта,
  отпечаток ключа метки (не ключ) и все файлы сборки — путь, sha256 после
  метки, `source_sha256` до метки, метод (`dct8-edge-v1`,
  `svg-jitter-v1`), перцептивный хэш изображений, а у страниц записей и их
  изображений — объект, вариант и версия (`object`, `variant`, `version`). Пишет
  `tools/cs/mark/release.py`; руками не правится — проверка `releases`
  ловит любое изменение, после которого метки времени недействительны.
- `<id>/manifest.json.tsr` — метка времени RFC 3161 (freetsa.org).
- `<id>/manifest.json.ots` — метка OpenTimestamps; полное доказательство в
  блоке Bitcoin — через несколько часов, `ots upgrade`.

Манифест и метки автор коммитит после выгрузки. Метки, не поставленные
без сети, — `python3 -m tools.cs mark stamp`. Чей файл и когда он вышел —
`python3 -m tools.cs mark verify <файл|адрес>`. Секретов и личных данных
здесь нет.
