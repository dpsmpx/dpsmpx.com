# Промпт: спецификация презентационной композиции, версия 1

Версионированная инструкция для сессии, которая пишет спецификации
композиции (`schemas/composition.schema.json`) для личных работ автора.
Изображение затем собирает инструмент (Д11): спецификация → HTML/SVG →
Chromium → PNG/JPEG (`tools/cs/render.py`). Генеративной модели нет;
«промпт» — это правила превращения брифа в спецификацию. Новая версия —
новый файл `…v2.md`; объекты ссылаются на версию (`prompt` в `item.yaml`).

## Вход

- Бриф объекта (`templates/content_brief.md`): цель, аудитории,
  площадки, утверждения.
- `docs/brand/VISUAL_SYSTEM.md`, `assets/brand/tokens.json`.
- `data/facts/facts.yaml` — только `FACT` с `public: true`.

## Правила

1. **Иерархия:** человек → имя и роль → инженерный контекст → ИИ →
   доказательство → декор. Человек — самый крупный объект; если
   портрета нет, вариант это обосновывает.
2. **Текст:** не больше 4 групп (`data-group`) и 3 размеров; минимум —
   16 px на 720 px высоты (на всех форматах — в пересчёте).
3. **Каждая строка — из фактов.** У спецификации `claims` — id фактов,
   на которые опирается каждое слово с утверждением (в т. ч. «движок»,
   «язык», «каждое слияние»). Числа — округлённые вниз, с датой
   («150 000+ … · 10.2026»), только из `allowed_wording`.
4. **Запреты:** `data/facts/forbidden.yaml` — ни одного срабатывания.
   «CI» не пишется; узел — «Проверка».
5. **Портрет:** только `REFERENCE_IMAGE` (A-001): `focus` — точка лица
   (доли кадра), `zoom` ≥ 1, `treatment` — natural / mono / duotone.
   Никакой ретуши черт. Интерьер не должен читаться: кадр и виньетка
   подбираются так, чтобы фон у лица уходил в `ink`.
6. **Цвет — смысл:** `kind` узлов цепочки — intent/architecture (человек),
   implementation (ИИ), verification (проверено), git, product.
7. **Варианты** — только под гипотезы брифа; у каждого `rationale`:
   что он проверяет и чем жертвует.
8. **Языки:** тексты `ru` и `en` — смысл один, формулировки родные для
   языка, не подстрочник.

## Выход

`content/items/<id>/spec/variant-<x>.yaml` по схеме `composition/v1`.
Проверка — `tools/check.sh` (schemas, claims), затем рендер
`python3 -m tools.cs render <id>`.
