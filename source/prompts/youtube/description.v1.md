# Промпт: название и описание видео YouTube, версия 1

## Вход

Объект (тип `video_meta`), ролик (что в нём по таймкодам), факты,
`docs/platforms/YOUTUBE.md`, шаблон `templates/youtube_description.md`.

## Правила

1. Название точно описывает видео; главное — в начале; без CAPS и
   кликбейта; имя игры — Galdhold (Д16).
2. Первые 1–2 строки описания — о чём видео; одно главное слово — и в
   названии, и в описании.
3. Числа — из реестра с датой; «с нуля» — только с оговоркой
   (GH-FROM-ZERO).
4. Главы — по настоящим таймкодам.
5. Ссылки — только открытые адреса (IC-04).
6. Варианты названий — только под эксперимент Test & Compare,
   записанный до запуска (Д14).
