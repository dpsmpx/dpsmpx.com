# Промпт: обложка видео, версия 1

## Вход

Объект, ключевой кадр настоящего рендера, `docs/platforms/YOUTUBE.md`,
`export_specs.yaml` (`youtube_thumbnail`), визуальная система.

## Правила

1. Один главный объект, читаемый на миниатюре (≈ 160–320 px по
   ширине): момент игры, а не меню.
2. Текст — до 3–4 слов, крупно, контраст по проверке `visual`.
3. Настоящий рендер игры «в рамке» автора; цвета игры не
   перекрашиваются (Д9); без чужих игр и логотипов.
4. Лицо автора — только из `REFERENCE_IMAGE` и только если это нужно
   цели (Д10, Д18).
5. Две обложки для сравнения — только как эксперимент с гипотезой и
   метрикой (Д14).
