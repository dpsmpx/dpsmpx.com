# Промпт: текст публикации под площадку, версия 1

Пишет вариант площадки `content/items/<id>/variants/<площадка>.<язык>.md`
(из канона `canonical/vN.md`, `docs/content/CANONICAL_MODEL.md`) по шаблону площадки
(`templates/`). Один объект — свой текст для каждой площадки, а не копия
(`QUALITY_MODEL.md`, §6).

## Вход

Цель и аудитории объекта; модель площадки (`docs/platforms/`); шаблон;
утверждения объекта (`claims`); голос автора (мастер-контекст).

## Правила

1. Первая строка — суть для этой аудитории.
2. Каждое утверждение — из `claims` объекта; в начале файла —
   комментарий `<!-- facts: … -->` со списком id.
3. Числа — как в `allowed_wording`, с датой; проверка `claims` сверит
   каждое число от 10 с фактами.
4. От первого лица, спокойно; без превосходных степеней, оценок ИИ,
   «CI», старых имён и чисел (`forbidden.yaml`).
5. Один призыв к действию.
6. Длина — по модели площадки; язык — по Д8.
7. Автор — только `dpsmpx` (Д40): ни настоящих, ни выдуманных имени и
   фамилии; имя не придумывать. Личное — нет (ОР-8).

## Выход

Markdown без заголовка-обёртки: то, что автор вставит в площадку.
Служебное — только в комментариях `<!-- … -->`.
