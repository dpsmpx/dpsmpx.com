# Бриф: <название> (CI-NNNN)

Этап 03_brief (`docs/content/CONTENT_PIPELINE.md`). Бриф отвечает на все
поля; пустое поле — «нет» с причиной, а не пропуск. Факты — только id
из `data/facts/facts.yaml`.

| Поле | Значение |
|---|---|
| Объект | CI-NNNN, `content/items/<id>-<slug>/item.yaml` |
| Опора (pillar) | из `CONTENT_STRATEGY.md`, §3 |
| Цель (objective) | одна фраза: что зритель должен понять или сделать |
| Аудитории | из `CONTENT_STRATEGY.md`, §2 — и чем они различаются для этого объекта |
| Площадки и форматы | площадка → формат из `data/platforms/export_specs.yaml` → язык (Д8) |
| За 2–3 секунды | что считывается с миниатюры |
| Ключевое сообщение | одна фраза голосом автора |
| Утверждения | id фактов; для каждого — где в работе |
| Чего не говорить | запреты из `forbidden.yaml`, относящиеся к теме |
| Визуальные требования | иерархия (`VISUAL_SYSTEM.md`, §4), портрет (Д10, Д18), токены |
| Ограничения | открытые решения (ОР), права, личное |
| Варианты | сколько и что проверяет каждый — только под цель |
| Критерии успеха | по чему критика и автор поймут, что цель выполнена |
| Зависимости | что ждёт автора |
