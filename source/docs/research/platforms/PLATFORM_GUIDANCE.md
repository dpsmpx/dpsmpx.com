# Требования и рекомендации площадок

Сводка официальных источников для `data/platforms/export_specs.yaml`
(Д13) и моделей площадок (`docs/platforms/`). У каждой строки — дата
чтения. «Рекомендация площадки» — вход, а не закон: что работает у
аудитории автора, решают его данные (Д15, фаза 6).

Статус: **проверено** — прочитано по первоисточнику в указанную дату;
**по записи** — прочитано сессией инициализации 04.10.2026, в этой
сводке не перечитано; **не подтверждено** — официального источника нет.

## YouTube

| Что | Значение | Источник | Статус |
|---|---|---|---|
| Обложка видео | рекомендовано 3840×2160 (Shorts — 2160×3840); 16:9; ширина ≥ 640; JPG/PNG; ≤ 2 МБ с телефона, ≤ 50 МБ с компьютера | support.google.com/youtube/answer/72431 | проверено 04.10.2026 — прежняя запись 1280×720 устарела |
| Шапка канала | загрузка от 2048×1152, 16:9; рекомендовано 2560×1440 (ТВ); безопасная зона текста и логотипов при 2048×1152 — 1235×338; ≤ 6 МБ | answer/10456525 | проверено 04.10.2026 |
| Фото канала | JPG/GIF/BMP/PNG без анимации, ≤ 15 МБ, отображается 98×98 | answer/10456525 | проверено 04.10.2026 |
| Handle | прежний handle держится 14 дней, оба адреса работают; затем его может занять другой; менять — не больше двух раз за 14 дней | answer/15920820 | проверено 04.10.2026 |
| Название, обложка, описание | точность названия, главное — в начале; читаемая обложка без перегруза; уникальное описание, первые строки — о чём видео; главы | answer/12340300, answer/12948449 | по записи |
| Test & Compare | до 3 названий/обложек; победитель — по доле времени просмотра; до 2 недель | answer/16391400, answer/13861714 | по записи |
| Раскрытие ИИ | реалистичный синтетический контент отмечается в Studio | answer/14328491 | по записи |
