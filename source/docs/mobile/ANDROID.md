# SocialMediaImage для Android — текущая версия

Основание — Д56 и ответы автора 14 ноября 2026. Отдельный пакет
com.dpsmpx.socialmediaimage, Kotlin/Compose, Android 11+, без подключения
ИИ. Существующее ядро Python — одно для CLI и приложения; сложный
анализ истории может выполняться через явно подключённый Termux.

## Рабочий сценарий

1. Открыть приложение и локальную рабочую копию проекта.
2. Подключить GitHub, импортировать материалы и профили с устройства.
3. Проверить факты, источники, устаревание и материалы.
4. Собрать новую версию и открыть весь сайт в обычном браузере.
5. Экспортировать полную новую сборку или последнюю опубликованную
   для обработки внешним ИИ; импортировать проверенный пакет обратно.
6. Сравнить и подтвердить конкретную версию, выложить после восстановления
   хостинга. Получить проверяемый итог, уведомление и дату выпуска.
7. Открыть последний выпуск без сети, включая все страницы и ресурсы.

Сборка не равна выпуску: ошибка сети или HTTP 200 с чужой заглушкой
не подтверждают релиз. Последний подтверждённый снимок не перезаписывается
незавершённой операцией. Секреты не входят в пакеты/предпросмотр/SAF.

## Этапы реализации

- М1: независимая сборка APK, встроенное ядро, рабочая копия, безопасные
  ZIP-пакеты, полный локальный HTTP-предпросмотр и экспорт.
- М2: материалы и проверка фактов на существующем конвейере; реестр
  источников, получение актуальных данных, различие измеренного и reported.
- М3: DocumentsProvider для системного выбора папки/файлов и внешних
  менеджеров. Рабочая копия доступна для правки; выпуски неизменяемы.
- М4: служба операций, импорт профилей, защищённые доступы в памяти,
  SSH с проверкой ключа, загрузка/скачивание сайта, журнал выпусков.
- М5: GitHub — рабочая ветка и сохранение конфликтов, подтверждённое
  вливание; площадки Telegram/VK/YouTube/Discord/GitHub/TikTok по Д33.
- М6: проверки, Lint и APK, самостоятельная ветка apk_debug, инструкция
  и приёмка автора после восстановления хостинга.

DP_Clock: фон и восстановление; его будильники и разрешения не копируются.

Код закрытых Galdhold/DPlang сюда не переносится.

## Реализованный путь текущей версии

Нативные экраны сайта, материалов, фактов/источников и настроек. Одно
ядро проверок и журнал CLI/Android. SFTP с обязательным known_hosts,
подготовкой вне public_html, резервом, сверкой и восстановлением;
Keystore и RAM-сеанс. Метка изображений и полная история Git — через
доверенный runtime в экспортируемом пакете Termux. GitHub main
подтверждается через просмотр PR; автоматического слияния нет.
Порядок действий и профиль — [CONNECTIONS.md](CONNECTIONS.md).

Приёмка на телефоне и настоящем хостинге — после восстановления и с
доступами автора; тестовые SSH/HTTP и криптографический круговой прогон
не объявляются такой приёмкой. Фактической выгрузки из облака нет.
