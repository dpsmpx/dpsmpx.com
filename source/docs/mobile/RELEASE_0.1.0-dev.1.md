# Android 0.1.0-dev.1 — 14 ноября 2026

Самостоятельное приложение SocialMediaImage, `com.dpsmpx.socialmediaimage`.
Исходники APK: `a03a3356f065105db570465fddcf4c1794e123f1`. Последующий коммит — только запись результатов
и передачи сессии; исполняемый код APK ему соответствует.

## Функции версии

- Полный локальный сайт в браузере, сборки staging/production и снимки.
- Экспорт всего нового/последнего сайта с исходниками, импорт пакетов.
- Материалы, проверка фактов/зависимостей, одобрение конкретного SHA.
- Свежие наблюдения GitHub; полный Git/patch-id/reported-анализ в Termux.
- GitHub: сравнение, обе копии конфликта, резерв и отдельный draft PR.
- SFTP: known_hosts, Ed25519, план, загрузка/сверка, резерв и восстановление;
  последнее подтверждённое издание целиком остаётся локально с датой.
  Для старого скачанного сайта дата и соответствие исходникам неизвестны.
- Метка Д41 штатным mark_build в Termux, подпись результата и точная
  проверка помеченной версии перед ручным подтверждением выкладки.
- Telegram Bot API, ручные пакеты/URL остальных площадок по Д33,
  журнал и сверка неопределённого исхода.
- PIN/Keystore, RAM-сеанс службы, хранилище SAF для внешних менеджеров;
  доступы не выдаются, снимки выпусков доступны только для чтения.

ИИ, редактор статей, точное расписание и панель Beget не входят — Д56.
Подключение и порядок работы — [CONNECTIONS.md](CONNECTIONS.md).

## Проверки

- Standard affected: 282 теста, 279 PASS / 3 штатных пропуска Chromium.
- Полный fast на переносимом jsonschema 4.17.3: те же 282, 279/3, все
  проверки зелёные. Это профиль встроенного конвейера APK; desktop-lock
  не менялся. Fast не выдаётся за браузерный рендер в Chromium.
- `python3 mobile/tools/check_android.py`: assembleDebug, unit и строгий
  lintDebug PASS. 3/3 теста без пропусков: HTTP/пути и реальный loopback
  SFTP с временными Ed25519-ключами. Отказ второй записи возвращает
  первую, прерывание восстанавливается, чужой ключ сервера отклоняется,
  .well-known сохраняется. Последние аппаратные подключения не нужны.
- APK: ZIP цел, v2-подпись верна; модули в app.imy и runtime Termux
  побайтно соответствуют исходникам; реестр фактов и схемы проверены.
