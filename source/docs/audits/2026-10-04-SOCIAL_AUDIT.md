**Сильные форматы (по содержанию).**
- Снимок + одна фраза «что сделано и почему» (№ 10, 13: «небо красивое,
  но не вписывается в воксельный стиль»; «генератор на принципах
  реальных ландшафтов, а не набор шумов») — понятно игроку, честно,
  показывает решение.
- Список изменений сборки (№ 23, 25, 30) — привычный формат дневника.
- Замер на устройстве с числами из логов (№ 9) — доказательство, а не
  оценка; числа устарели (сентябрь, до смены рендера) — повторять
  нельзя (`data/facts/facts.yaml`, `GH-PERF-2026-09-30`).
- Метод работы с ИИ своими словами (№ 31–32, 39, 79). Эссе № 79 («ИИ
  может забывать сессию. Проект — не обязан забывать») — лучшая
  формулировка позиционирования, сделанная самим автором.
- История начала (№ 80: «братья сказали — классно бы поиграть Cube
  World на телефоне») — человеческая, понятная любому.

**Перегруженные и слабые форматы.**
- Пересказ оценок ИИ (№ 5–6, 28, 37–38, 43, 60, 66–67, 69, 72–73, 76–77)
  — длинные ответы чат-ботов с баллами и сравнениями («9.5/10», «быстро
  для студии с бюджетом $500k», «99% разработчиков», сравнение с
  Godot/Veloren, заголовок «I'm the best programmer in the world!»).
  Для читателя это не доказательство, а для бренда — риск выглядеть
  как «ИИ сказал, что мой проект хороший». То, что в них верно,
  переводится в проверенный факт (`CLAIM_POLICY.md`, §4).
- Ссылка на Telegraph без своей строки — читатель не знает, зачем
  открывать.
- Пустые записи-снимки без подписи (№ 11, 14, 20, 56).
- Прогресс в процентах без определения (№ 62) — проценты не сходятся с
  оценкой в README Galdhold (43 % / 31 % на 03.10.2026).

**Что не переносить на другие площадки без переработки.**
- Всё `ai_meta` — не переносить вовсе.
- Личное (№ 44, 53, 75, 58, 65) — по ОР-8. № 75 раскрывает работу,
  доход и учёбу; № 67 обсуждает несколько аккаунтов сервиса ИИ и обход
  связывания аккаунтов — риск для репутации и правил сервиса (ОР-9).
- Числа сентября (FPS, строки кода, «18–23 дня») — только из реестра
  фактов с датой.
- «Работает на Android и Windows», «CI» — устарело или неверно:
  Windows-сборка на настоящей Windows не запускалась; GitHub Actions с
  03.10.2026 не используются (`facts.yaml`).

**Кому что интересно.**
- Игроку: снимки, видео, «что нового в сборке», история начала.
- Разработчику: замеры, архитектурные решения (№ 33), метод (№ 39, 79).
- Ни тем, ни другим: оценки ИИ, проценты без определения.
