вокруг ИИ**: записанные решения с историей, правила для агента,
проверки, аудиты на дату; новая сессия восстанавливает состояние из
репозитория (AU-MEMORY). Сам автор сформулировал это в эссе (дневник,
№ 79, 04.10.2026): «ИИ может забывать сессию. Проект — не обязан
забывать.» Итог — позиционирование Д4.
