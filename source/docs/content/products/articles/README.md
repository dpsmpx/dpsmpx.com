# Статьи автора

Раздел статей (Д42): тексты, которые автор пишет сам. На сайте — `/articles/`
(`docs/platforms/WEBSITE.md`, «Статьи»), в репозитории — объекты контента с
`category: article` в `content/items/`; здесь — бриф и исследование каждой
статьи.

Как добавить статью:

1. Объект: `item.yaml` с `type: article`, `category: article`, целью,
   аудиторией и `website.toc: true`; `slug` — адрес `/articles/<slug>/`.
2. Канон `canonical/v1.md` — текст автора (`generation.provider: human`);
   сессия меняет только разметку (заголовки, списки, схемы — блоки кода) и
   подстановки (`{{fact:…}}`, `{{progress:…}}`) и перечисляет правки в
   брифе.
3. Исследование и бриф — `<slug>/BRIEF.md`: каждое утверждение о проектах —
   с фактом реестра или отмечено «нет факта»; проекты с юридическим риском —
   без имени и подробностей (Д42).
4. `canonical seal`, `adapt --platform website --lang ru`, `variant seal`;
   критика отдельным проходом; одобрение и публикация — автор (Д12).
