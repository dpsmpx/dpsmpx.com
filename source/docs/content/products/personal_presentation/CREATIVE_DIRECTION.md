# Творческое направление: презентационное изображение (CI-0001)

Этап 04_draft. Из брифа (`BRIEF.md`) — в спецификации композиции
`content/items/CI-0001-personal-presentation/spec/variant-{a,b,c,d}.yaml`
(схема `composition/v1`). Рендер — программная композиция (Д11),
инструкция — `prompts/image/presentation-composition.v1.md`.

## Общая идея

**Инженерная мастерская, в центре — человек.** Тёмный графит, едва
заметная сетка, тёплый боковой свет на лице, интерьер уходит в тень.
Справа от человека — кто он и как работает: цепочка работ слева
направо, где цвет — смысл (`VISUAL_SYSTEM.md`, §2, §6):

```
Замысел → Архитектура → Реализация с ИИ → Проверка → Git → Продукт
 человек    человек          ИИ          проверено   память   результат
                                   ◆ приёмку решаю я
```

Ромб — ворота решения человека между проверкой и Git: каждое слияние
принимает автор (AU-METHOD, GH-COMMITS). Узел «Проверка», а не «CI»
(ME-NO-CI). Последний узел — воксель: свой векторный знак «продукта»,
не ассет игры (Д9, Д17).

Внизу — доказательства, а не эпитеты: что за проект и масштаб с датой
(GH-LOC, GH-CHECKS — «10.2026»). Чисел без даты нет.

## Варианты — что проверяет каждый

| Вариант | Макет | Гипотеза | Что жертвует |
|---|---|---|---|
| **A professional** | портрет слева на 44 % ширины; справа имя, роль, подзаголовок, цепочка с легендой, две плашки-доказательства | баланс человека, метода и доказательства — лучше всего для профессиональной аудитории | плотность: 4 группы текста — на пределе |
| **B technical** | портрет уже (32 %); схема коробками с двумя воротами; три числа-плитки | инженерная подача убедит техническую аудиторию сильнее | человек отходит на второй план; больше текста |
| **C cinematic** | портрет на 78 % ширины, тёплый дуотон, имя поверх тени, три шага тонкой линией | образ и настроение запоминаются лучше перечня фактов | почти нет доказательств; виден интерьер |
| **D minimal** | без портрета: имя, роль, цепочка | держится ли знак без лица; запасной вариант для мест, где лицо не нужно | нарушает иерархию «человек первым» |
