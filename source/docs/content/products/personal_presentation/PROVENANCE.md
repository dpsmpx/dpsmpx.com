# Происхождение: презентационное изображение (CI-0001)

Правила — `docs/PROVENANCE.md`. Записи по каждому файлу — 
`content/items/CI-0001-personal-presentation/provenance.yaml` (пишет
`tools/cs/render.py`; руками не правятся).

## Входы

| id | Что | Как использован |
|---|---|---|
| A-001 | фотография автора, `REFERENCE_IMAGE` | портрет: масштаб и сдвиг (точка лица `focus`, `zoom`), тон (natural; у C — дуотон), виньетка и маски краёв; черты не меняются (Д10, Д18) |
| A-002 | шрифты IBM Plex Sans и Mono (OFL 1.1) | весь текст |
| A-003 | токены визуальной системы | цвета, шкала, пределы проверок |

Других входов нет: сетевые запросы при рендере запрещены и
проверяются (`external_requests` в раскладке пуст). Знак «продукта» в
цепочке — свой векторный воксель, не ассет игры (Д9, Д17).

## Метод

Спецификация (`spec/variant-*.yaml`) → HTML/SVG (`tools/cs/render.py`)
→ Chromium через Playwright (`tools/render/render.js`) → JPEG/PNG и
раскладка `*.layout.json`. Рендер воспроизводим: та же спецификация даёт
тот же файл (`tests/test_render.py`). Каждый формат рендерится заново.

## Выходы

`renders/` — все варианты для критики (лента RU/EN, шапка YouTube RU,
GitHub EN); `exports/` — выбранный вариант по форматам брифа. Список с
назначением — `OUTPUTS.md`; хэши, входы, спецификация и её хэш, промпт,
дата — `provenance.yaml`.
