# Бриф: страница прогресса экосистемы (CI-0002)

Этап 03_brief (`docs/content/CONTENT_PIPELINE.md`). Поручение автора
5 октября 2026: перенести черновую визуализацию «24 дня» в систему и
сделать из неё часть сайта, воспроизводимую из доказательств. Устройство
страницы, данные и граница публичного — Д38 и `docs/platforms/WEBSITE.md`,
«Страница прогресса».

| Поле | Значение |
|---|---|
| Объект | CI-0002, `content/items/CI-0002-ecosystem-progress/item.yaml` |
| Опора (pillar) | PROCESS — метод работы, показанный через результат и его следы в истории (`CONTENT_STRATEGY.md`, §3) |
| Цель (objective) | за несколько минут показать, сколько построено за 24 дня, как одна игра выросла в экосистему независимых репозиториев, как параллельно шли проекты и как созрели проверки, документы и архитектура — только по доказательствам |
| Аудитории | professional и collaborators — масштаб и дисциплина работы; developers и ai_developers — как устроена разработка с ИИ (ветки, PR, журналы решений, проверки) |
| Площадки и форматы | только сайт: `website.ru` (`/progress/`), `website.en` (`/en/progress/`), формат `page`; другие площадки — ссылкой на страницу, отдельными объектами |
| За 2–3 секунды | заголовок, срез на 5 октября и первая фигура: столбцы по дням, где после 3 октября появляются новые репозитории |
| Ключевое сообщение | «За 24 дня одна игра выросла в экосистему из независимых репозиториев — с решениями, проверками и знанием, которые записаны и измеряются» |
| Утверждения | числа — подстановки `{{progress:…}}` из набора `2026-10-05` (измерения git, Д38); стадии и роли проектов — факты `GH-STAGES`, `DP-STAGE`, `VRF-*`, `PRF-*`, `LRN-*`, `MKT-*`, `META-*`, `SMI-*` (фигуры «срез» и «карта»); `GH-NAME`, `META-NO-DEPS` — в тексте; вехи — `data/progress/milestones.yaml` с источниками |
| Чего не говорить | «в N раз быстрее», оценки ИИ, «уникально» (AH-*); «CI» (ME-NO-CI); прежнее имя игры — только с «прежде»; DPlang «готов» (CL-DPLANG-READY); проценты готовности (GH-READINESS — не публичный); имя DPpass и всё о нём, кроме чисел в общих суммах (решение автора 05.10.2026, PROJECT_MAP); время суток коммитов (личное, Д2) |
| Визуальные требования | тема сайта и токены бренда (Д9, `VISUAL_SYSTEM.md` §2, §7): цвет — смысл (решения — `human`, работа ИИ — `ai`, проверено — `verified`, git — `mist`); графики без скриптов (CSP); каждая фигура — с таблицей значений; 390 и 1280 px |
| Ограничения | Д12: на рабочем сайте — только после одобрения автора; Д17: о закрытых проектах — только факты и вехи; набор данных — срез на 05.10.2026 08:00 МСК, не «живые» числа |
| Варианты | один: текст страницы на двух языках. Отдельных вариантов «на всякий случай» нет — цель одна, площадка одна |
| Критерии успеха | у каждого числа есть источник или формула; читатель без графиков понимает выводы по тексту и таблицам; на телефоне ничего не уходит за край; нет имени закрытого проекта; критика без fatal |
| Зависимости | автор: одобрение `website.ru` и `website.en` (`approve`) и публикация (`publish … --production`) |
