# Discord

Аккаунт и сервер `dpsmpx` — **UNKNOWN / AUTH REQUIRED** (аудит, §7).
Структура сервера, правила, роли и онбординг не придумываются; модель
ниже — целевая, для решения ОР-6 и для этапа Playtest Galdhold (К17 в
плане «Соцсети и публичный образ»).

## Модель (целевая)

| Поле | Значение |
|---|---|
| Audience | игроки Playtest, соавторы, заинтересованные разработчики |
| Purpose | сообщество и отзывы; объявления сборок |
| Primary content | COMMUNITY, RELEASE |
| Secondary content | PROCESS (короткие обновления), вопросы к сообществу |
| Length | объявление — экран без прокрутки; подробности — ссылкой |
| Visual format | изображение объявления 16:9 1280×720; баннер сервера — по требованиям Discord (проверить при создании) |
| CTA | «попробуйте сборку», «напишите отзыв в #…» |
| Posting rhythm | по сборкам и вехам |
| Discoverability | приглашения с других площадок; Discovery — только для больших Community-серверов |
| Retention mechanism | понятный первый шаг, роли по интересам, ответы автора |
| Cross-platform role | место разговора; новости приходят сюда из дневника |

## Онбординг (официальные рекомендации Discord — input)

Главное правило: **новый участник не должен попадать в перегруженное
пространство без понятного первого шага.**

- Community Onboarding: каналы по умолчанию (что видят все), вопросы
  при входе (выбор ролей и каналов), связь ответов с ролями. Требования
  (по справке Discord, проверить при настройке): не меньше 7 каналов по
  умолчанию, из них не меньше 5 — открытых для сообщений всем.
- Server Guide: приветствие, задачи новичка («New Member To-Dos»),
  страницы ресурсов.
- Rules Screening — после онбординга.

Предложение структуры для малого сервера (до решения автора):
`#start-here` (правила и первый шаг) · `#announcements` · `#devlog` ·
`#screenshots` · `#feedback` · `#bugs` · `#general`; вопрос онбординга:
«Вы игрок / разработчик / пришли из-за ИИ-разработки?» → роли и
каналы.

Шаблон — `templates/discord_announcement.md`.

## Публикация

Вебхук канала даёт полную автоматизацию объявлений без бота (Execute,
Edit, Delete; текст до 2000 знаков, до 10 embed, файл до 20 МиБ); URL
вебхука — секрет. Адаптер — фаза П6, после ОР-6
(`docs/research/publishing/PLATFORM_APIS.md`, §4).
