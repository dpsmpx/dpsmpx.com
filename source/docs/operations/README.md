# Эксплуатация

Как система работает «в поле»: окружения, учётные данные, резервные
копии, восстановление, проверка здоровья (постановка §30–31, §55,
§65–67, §104–109; Д12, Д24, Д25, Д30).

| Документ | Отвечает на вопрос |
|---|---|
| `ENVIRONMENTS.md` | development, staging, production: что где живёт и чем отличается |
| `CREDENTIALS.md` | где токены, как подключить площадку, ротация, отзыв, утечка |
| `BACKUP.md` | что, куда и как часто копировать; проверка копии |
| `DISASTER_RECOVERY.md` | что делать, если потерян сайт, репозиторий, токен, площадка, ИИ, медиа |

Быстрые команды:

```sh
python3 -m tools.cs health             # площадки, учётные данные, сайт, хранилище, журнал
python3 -m tools.cs bundle             # выгрузка всей базы (резервная копия)
python3 -m tools.cs publish --due      # что наступило или ждёт повтора (пробный прогон)
python3 -m tools.cs site serve         # локальный staging сайта
```
