Экосистема

Система, которую я строю: проекты по слоям — что каждый делает и на какой он стадии.

Управление

  • DPmetaApp — управление экосистемой: одно приложение автора для Android; внутри уже подсистема ИИ для параллельных сессий

Продукты

  • Galdhold — воксельная action-RPG с открытым процедурным миром (закрыты этапы: движок, живое поселение, регионы; идёт подготовка версии 1)
  • DPlang — разрабатываю собственный язык программирования — DPlang (язык на ранней стадии: компилятор в разработке, собирает программы для Linux, Windows и Android)
  • DP AIM Trainer — замер реакции и разминка перед шутерами: конструктор замеров, рекорды по параметрам, реплеи лучших попыток (C++ и SDL3 для Windows и Linux; выполнено 22 задачи плана из 30)
  • DP_Clock — своё приложение часов для Android: будильники, таймеры, мировые часы, виджеты (версия 0.11.0: MVP и будильник целиком; выпуска пока нет)
  • Andors-Love — пошаговая RPG на C++

Инструменты и обеспечение

  • DP-Verify — общий каркас проверок для репозиториев автора (кандидат версии 1.0; его проверки подключены в Galdhold)
  • DPmonetization — анализ портфеля проектов: от доказательств к решению — каркас ядра
  • True Joint Tile Maker — редактор пиксельной графики и карт для Andors-Love (версия 1.6: перенесён на C++ и SDL3, для Windows и Linux)
  • DPvisualisation — интерактивная модель экосистемы на реальных данных

Знание и публикация

  • DPprofile — проверяемая история пути разработки — источники, факты, хронология (выполнено 4 этапа из 6; текст книги не пишется)
  • SocialMediaImage — система контента и сайт dpsmpx.com (сайт выгружен на хостинг 5 октября 2026)
  • DPlearn — система обучения, где «освоено» вычисляется из доказательств (версия 0.1.0: ядро и пилотный домен готовы)
  • DP_game_market_analytic_system — воспроизводимый анализ рынка игр (версия 0.3.0 до выпуска: командная строка, 358 тестов, данные пока синтетические)

Синхронизация

  • DPmeta — карта экосистемы, контракты между репозиториями и риски (три прохода по экосистеме — 5 октября 2026)

Инфраструктура
